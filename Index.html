一般社団法人 足の８０２０ — PUBLIC API

API仕様書

Version 1.0.0  ·  2026年5月公開  ·  stable

このAPIは、ウォーキングアプリ・健康管理サービス・自治体システムが「足の８０２０ウォーキング」に接続するためのオープンインターフェースです。認定パートナーになることで、参加者の歩行データを受け付け、社会貢献額の試算・通知書の発行が可能になります。

概要・設計思想

「足の８０２０」APIは、「歩く」という日常行為を社会貢献として定量化するためのインターフェースです。接続するアプリやサービスは、参加者の歩行記録を送信するだけで、医療費削減試算・社会貢献通知書の発行・自治体単位の集計レポートを受け取ることができます。

設計の原則は３つです。第一にオープン——キャリア・OS・アプリを問わず誰でも接続できます。第二にプライバシーファースト——個人を特定するデータは取得せず、集計・匿名化されたデータのみを扱います。第三にエビデンスベース——試算ロジックは厚生労働省・国立長寿医療研究センターの公開データに基づき、根拠を全て公開します。

ベースURL

# 本番環境（2026年5月〜）
https://ashino8020.github.io/api/v1

# 現在はスタティックJSON。動的APIへの移行時もエンドポイント構造は維持します。

認証

現バージョン（v1）では、パートナー登録後に発行される partner_key をリクエストヘッダーに含めます。

GET /v1/calculate
Authorization: Bearer your_partner_key_here
Content-Type: application/json

パートナー認定制度

「足の８０２０認定パートナー」は、以下の条件を満たすアプリ・サービスに付与されます。認定を受けると partner_key の発行・公式サイトへの掲載・共同プレスリリースの権利が得られます。

条件内容
歩行記録機能1日20分以上（または約1.2km）の歩行を記録・判定できること
同意取得参加者からAPIへのデータ送信について明示的な同意を得ていること
非営利目的の明示足の８０２０への連携が非営利・社会貢献目的であることをUI上で表示すること
プライバシー保護個人を特定する情報をAPIに送信しないこと

パートナー申請は ashino8020.jp の問い合わせフォームから受け付けています。

エンドポイント

GET /v1/calculate stable 社会貢献額を試算する

歩行実績データを受け取り、医療費・介護費の削減推計額と社会貢献スコアを返します。試算ロジックは厚労省・国立長寿医療研究センターのデータに基づきます。

クエリパラメータ

パラメータ型説明
walking_daysrequiredinteger5月中に歩いた日数（1〜31）
avg_minutesrequiredinteger1日あたり平均歩行時間（分）。最小値20
age_grouprequiredstring30s / 40s / 50s / 60s / 70plus
regionoptionalstringcity（大都市）/ urban（地方都市、デフォルト）/ rural（過疎）
yearsoptionalinteger継続参加年数（1〜10、デフォルト1）

レスポンス例

// HTTP 200 OK
{
  "status": "ok",
  "version": "1.0.0",
  "result": {
    "annual_saving_jpy": 72000,        // 今年度推計削減額（円）
    "cumulative_saving_jpy": 84960,    // 累計削減額（継続年数分）
    "breakdown": {
      "medical_jpy": 44640,            // 医療費削減分
      "care_jpy": 20160,               // 介護費削減分
      "other_jpy": 7200                // その他社会的費用削減分
    },
    "achievement_rate": 0.81,          // 達成率（25日/31日）
    "social_contribution_score": 82,   // 独自スコア（0〜100）
    "equivalent": {
      "school_meals": 314,             // 給食換算（食）
      "child_activity_days": 56         // 子ども体験活動換算（日）
    }
  },
  "evidence": {
    "source": "MHLW-2023 / NCGG-SGS Cohort",
    "note": "参考推計値です。個人差があります。"
  }
}
POST /v1/records beta 歩行記録を登録する

参加者の歩行記録を送信します。個人を特定する情報（氏名・メールアドレス・電話番号等）は送信しないでください。パートナーアプリ内部のユーザーIDを匿名IDとして使用します。

      "duration_minutes": 15,

GET /v1/certificate stable 社会貢献通知書データを取得する

月末（5月31日）以降に呼び出すと、参加者の社会貢献通知書データをJSON形式で返します。アプリ内でのPDF生成・表示にご利用ください。

クエリパラメータ

パラメータ型説明
record_idrequiredstringPOST /v1/records で返却された record_id
display_nameoptionalstring通知書に表示する名前（アプリ側で設定）。未指定時は「参加者」

GET /v1/city-report beta 自治体単位の集計レポートを取得する

自治体コード（総務省JISコード）を指定すると、その自治体の参加者集計・推計社会保障費削減総額を返します。自治体の健康施策レポートや住民向け広報にご活用ください。

クエリパラメータ

パラメータ型説明
city_coderequiredstring総務省JIS市区町村コード（例：27203 = 大阪府泉大津市）
yearoptionalinteger対象年度（デフォルト：直近年）

レスポンス例

// HTTP 200 OK
{
  "city_code": "27203",
  "city_name": "大阪府泉大津市",
  "year": 2026,
  "participants": 1842,
  "avg_achievement_rate": 0.74,
  "total_saving_jpy": 94284000,     // 市全体の推計削減額
  "avg_saving_per_person_jpy": 51186,
  "yoy_change": +0.12,              // 前年比参加者増減率
  "note": "推計値。個人情報は含みません。"
}

スキーマ定義

age_group の値

値対象年齢年間削減基準値
30s30代28,000円
40s40代45,000円
50s50代72,000円
60s60代98,000円
70plus70代以上135,000円

基準値は厚生労働省・NCGG-SGSコホート研究データより。地域補正・達成率・継続年数係数を乗じて最終値を算出。

エラーコード

HTTPステータスcode説明
400INVALID_PARAMパラメータ形式・値域エラー
401UNAUTHORIZEDpartner_key が無効または未指定
403NOT_CERTIFIEDパートナー認定が完了していない
404RECORD_NOT_FOUND指定した record_id が存在しない
422PII_DETECTED個人情報と思われるデータが検出された
429RATE_LIMITEDレート制限超過
503MAINTENANCEメンテナンス中（5月10日〜31日以外は制限あり）

{

  "message": "walking_days must be between 1 and 31",

クイックスタート

以下のコードで、5分で試算APIを呼び出せます。

JavaScript（ブラウザ / Node.js）

// 社会貢献額を試算する
const res = await fetch(
  'https://ashino8020.github.io/api/v1/calculate' +
  '?walking_days=22&avg_minutes=30&age_group=50s®ion=urban&years=2',
  {
    headers: {
      'Authorization': 'Bearer YOUR_PARTNER_KEY',
      'Content-Type': 'application/json'
    }
  }
);

const data = await res.json();
console.log(`年間削減額: ${data.result.annual_saving_jpy.toLocaleString()}円`);
console.log(`給食換算: ${data.result.equivalent.school_meals}食分`);

Python

import requests

params = {
    "walking_days": 22,
    "avg_minutes": 30,
    "age_group": "50s",
    "region": "urban",
    "years": 2
}
headers = {"Authorization": "Bearer YOUR_PARTNER_KEY"}

res = requests.get(
    "https://ashino8020.github.io/api/v1/calculate",
    params=params, headers=headers
)
data = res.json()
print(f"年間削減額: {data['result']['annual_saving_jpy']:,}円")

プライバシーポリシー

このAPIは個人情報保護法・GDPRの原則に従い設計されています。APIに送信できるのは匿名化・ハッシュ化されたデータのみです。氏名・メールアドレス・住所・電話番号・生年月日の送信は禁止されており、検出された場合は 422 PII_DETECTED を返します。

足の８０２０が保持するデータは、自治体・年齢層・地域別の集計値のみです。個人を再識別できるデータは一切保持しません。研究目的でのデータ提供は、倫理委員会の承認と参加者の明示的同意を条件として別途協議します。
